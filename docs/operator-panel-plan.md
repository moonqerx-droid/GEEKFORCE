# План операторской панели (apps/operator)

Владелец: Участник 4.

## Экраны

### 1. Очередь обращений

- список эскалированных тикетов;
- сортировка по срочности, затем по времени создания;
- краткая карточка: сервис, срочность, время, статус;
- индикатор связи с массовым инцидентом.

### 2. Карточка эскалации

Полный контекст без перечитывания чата:

- исходное обращение;
- уточняющие вопросы и ответы;
- предполагаемая проблема;
- уровень и причина срочности;
- выполненные действия и результат каждого;
- текущий статус;
- AI-резюме.

### 3. Экран массового инцидента

- список связанных обращений;
- общая причина / предполагаемый сервис;
- кнопка рассылки статуса связанным пользователям.

## Эндпоинты

```

GET  /api/operator/tickets
GET  /api/operator/incidents
POST /api/operator/incidents/{id}/broadcast

```

## Definition of Done

Специалист видит приоритетную очередь, получает полный контекст и может создать либо обновить массовый инцидент.

## Стек

Пока не зафиксирован. Заглушка — статический HTML. Финальный стек согласуется с командой.
