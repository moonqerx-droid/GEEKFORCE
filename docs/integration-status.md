## Контракт для фронтенда и оператора

- Все существующие endpoints сохранены, источник схем — `/openapi.json`.
- Срочность API: `low`, `normal`, `high`, `critical`.
- Результат шага API: `helped`, `not_helped`, `cannot_perform`.
- Использовать `current_step.code` из ответа; не задавать названия шагов в UI вручную.
- В `CLARIFYING` может быть несколько последовательных вопросов. Число зависит от срочности и уже известных фактов.
- При ИБ или массовом сбое первое сообщение может сразу вернуть `ESCALATED`.
- `helped` переводит в `VERIFYING`; только явное подтверждение закрывает обращение.
- `escalation_card` — дополнительный объект: исходное обращение, факты, вопросы/ответы, выполненные шаги, текущий результат, причина передачи, команда и резюме. У старых обращений может быть `null`.
- Рабочий локальный UI: `/debug`; очередь и карточка: `/debug/operator`.

1. `README.md` содержит маркеры `BDS:create_file` и текст предполагаемых `CONTRIBUTING.md`/`.gitignore` внутри README. Нужна очистка и создание отдельных файлов, если они действительно нужны.
2. `apps/operator/index.html` — статическая заглушка без запросов API; в backend уже есть рабочая debug-очередь.
3. `services/incidents` пока содержит README, реализации кластеризации нет. Описанные `/api/operator/incidents` и `/broadcast` ещё не реализованы.
4. Compose пересекается с нашим. Для AI build context теперь должен быть корнем репозитория, Dockerfile — `apps/api/Dockerfile`. Нельзя заменять его старым `context: ./apps/api`.
5. В Compose оператора панель использует 3100, хотя README указывает 3000. Если панель будет на 3100, добавить origin в `CORS_ORIGINS`.
6. `.idea` — локальные файлы IDE; перед интеграцией стоит убрать их из коммита коллеги.

## Что исправлено при подключении AI

- Перевод `medium` → `normal`, `cannot_perform` → `cannot_do` на границе компонентов.
- Сохранение заданных вопросов и результата проверки в БД; миграция `20260926_0002`.
- Каждый ход нового диалога сохраняется одной транзакцией; ошибка откатывает изменения.
- Старые обращения продолжают legacy-сценарий, новые используют TriageEngine.
- Неуверенный ответ «не знаю, работает ли» больше не закрывает обращение.
- CRM-инструкция удаления данных ограничена одним сайтом; инструкции учитывают Windows/macOS.
- Alembic использует `DATABASE_URL`, включая постоянную базу Docker `/data/helpflow.db`.
