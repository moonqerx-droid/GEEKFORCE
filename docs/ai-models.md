# Понимание запросов: что выбрали и почему

Замеры 28.09.2026 на MacBook M2, 16 ГБ, эталон `apps/api/tests/golden/dialogues.yaml`
(`python -m app.eval_dialogues [--semantic]`).

## Слои

| Слой | Что даёт | Цена |
|---|---|---|
| Ключевые слова сценариев | базовое распознавание | ~0 мс |
| + словоформы и опечатки (`pymorphy3`, `rapidfuzz`) | «очереди печати», «принтр», «ранботало» | ~1 мс |
| + смысл (эмбеддинги `bge-m3` в Ollama) | сленг и перефразы: «комп тупит», «скинь пароль от админки» | ~100 мс, индекс примеров 4–18 с один раз, кеш на диске |

Большую LLM (`qwen3.5:9b`) для понимания не используем: на этой машине ход занимал до 90 с.
Она остаётся для формулировки ответа по документам компании.

## Результаты

Доля обращений, для которых выбран правильный сценарий.

| Набор | Слова + словоформы и опечатки | + смысл |
|---|---|---|
| Контрольная группа 3 (40 фраз, написаны до первого прогона смыслового слоя) | 78 % | **90 %** |
| Все фразы на понимание (116) | 86 % | **97 %** |
| Поведение в диалоге (22 диалога) | 100 % | 100 % |

До исправления опечаток (только ключевые слова) на первых 36 фразах распознавание было 92 %,
с опечатками — 95 %; фраза «Вчера всё ранботало, сигодня…» распознаётся только после исправления.

## Правило совмещения

Смысловой слой меняет выбор ключевых слов только когда уверенно лидирует (сходство ≥ 0,70,
отрыв от второго места ≥ 0,05–0,06). Сценарии безопасности и запрос чужих паролей, найденные
по словам, не переопределяются; поднять их по смыслу можно только при сходстве ≥ 0,75 и отрыве
≥ 0,10. Массовый сбой по смыслу не определяется никогда — нужна явная фраза вроде «у всех».
На эталоне модель ошибалась лишь там, где её отрыв был меньше 0,05.

## Альтернативы

- `T-lite` (Т-Банк), `YandexGPT-5-Lite-8B` — сильный русский, но это генеративные модели 7–8B:
  для классификации медленнее и не точнее эмбеддингов на наших примерах.
- GigaChat API / Yandex AI Studio — через OpenAI-совместимый провайдер (`AI_PROVIDER=openai`);
  по умолчанию выключено: данные обращений не должны уходить из компании.
