# База кодов ошибок

Каждый файл — коды одной области. Сотрудник пишет «впн не подключается, ошибка 809» —
помощник находит код здесь, объясняет простыми словами, что он значит, и ведёт по шагам
именно для этого кода, а уже потом — по общим шагам сценария. Код и его значение попадают
в карточку специалиста.

Формат записи:

```yaml
playbook: vpn_connection        # сценарий по умолчанию для всех кодов файла
codes:
  - code: "809"                 # как пишут: 809, 0x800CCC0E, 80070005, DNS_PROBE_FINISHED_NXDOMAIN
    also: ["0x329"]             # другие записи того же кода (необязательно)
    title: Сеть не пропускает VPN          # коротко, для заголовка и карточки
    meaning: Сеть, к которой подключён компьютер, …   # что это значит, простыми словами
    escalate_after_steps: false # true — если шаги кода не помогли, сразу к специалисту
    decides_scenario: true      # false — код общий (HTTP 403/502) и не меняет выбранный сценарий
    steps:                      # как в сценариях; requires_admin: true — делает специалист
      - id: phone_hotspot
        title: …
        instruction: …
```

Шестнадцатеричные коды можно писать как угодно: `0x00000709`, `0x709` и `709` в записи
`0x…` — одно и то же. Добавить код — дописать запись; код движка менять не нужно.
