# Документы компании для демо

Пример того, что руководитель поддержки загружает в раздел «База знаний». `python -m app.seed_demo`
загружает их сам (обновлённый файл заменяет прежнюю версию); их же можно загрузить вручную через
интерфейс. Компания вымышленная, адреса `company.local` не существуют.

| Файл | Документ | Примеры вопросов |
|---|---|---|
| `password-rules.md` | Правила паролей | Раз в сколько дней меняется пароль? Что делать, если учётка заблокирована? |
| `vpn-guide.md` | Инструкция по VPN | Какой VPN-клиент ставить? Что значит ошибка 809? |
| `travel-regulations.md` | Регламент командировок | Какие суточные за рубежом? Когда сдавать авансовый отчёт? |
| `vacation-sick-leave.md` | Отпуска и больничные | Сколько дней отпуска положено? За сколько подавать заявление? |
| `workplace-equipment.md` | Рабочее место и оборудование | Как получить второй монитор? Что делать при утере ноутбука? |
| `information-security.md` | Информационная безопасность | Куда пересылать подозрительное письмо? Можно ли подключать флешку? |
| `office-rules.md` | Офис | Как заказать пропуск гостю? Как забронировать переговорную? |
| `software-and-access.md` | Программы и доступы | Как быстро установят программу? Как получить доступ к папке? |
| `email-rules.md` | Корпоративная почта | Какой максимальный размер вложения? Как включить автоответ? |
| `support-rules.md` | Техподдержка | Когда работает поддержка? Как быстро ответит специалист? |

Премий и зарплаты в документах нет специально: на такие вопросы помощник честно передаёт вопрос
специалисту, а не угадывает.
