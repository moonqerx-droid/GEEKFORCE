# Документы компании для демо

Пример того, что руководитель поддержки загружает в раздел «База знаний». `python -m app.seed_demo`
загружает их сам; их же можно загрузить вручную через интерфейс. После загрузки помощник отвечает
по ним с цитатой: «Какие суточные в командировке?», «Раз в сколько дней меняется пароль?»,
«Что значит ошибка 809 в VPN?».
