# Офис

Офис открыт по будням с 8:00 до 21:00. В выходные дни вход возможен по заявке руководителя.

## Пропуска

Пропуск выдаёт служба безопасности в первый рабочий день. Если вы потеряли пропуск, сообщите в службу безопасности: временный пропуск выдаётся на один день.

## Гости

Пропуск для гостя заказывается на портале самообслуживания не позднее чем за один рабочий день до визита. Гостя встречает на ресепшене сотрудник, который заказал пропуск.

## Переговорные

Переговорные бронируются через календарь Outlook. Бронь без подтверждения снимается через 15 минут после начала встречи.

## Парковка

У офиса есть парковка: для сотрудников она бесплатная, место выдаётся по заявке в административный отдел. Для гостей парковка платная.
