# services/incidents

Incident Radar — объединение похожих обращений в возможный массовый инцидент.

Владелец: Участник 4.

## Назначение

- сравнивать новое обращение с активными;
- создавать кластер при достаточном сходстве;
- показывать оператору возможный массовый инцидент;
- связывать подходящие обращения;
- сообщать пользователю о возможной массовой проблеме;
- позволять оператору отправить обновление всем связанным пользователям.

## Статус

Пустой каталог. Реализация — после фиксации API-контрактов.
